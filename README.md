# Interface experiments for `embedded-cal`

This repository contains code experiments that should help shape the [`embedded-cal`]traits.

Outputs of this repository have been processed into its [issue 1].
While not all experiment outcomes have been fully realized in `embedded-cal` at the time of writing,
they have influenced its architecture,
the experiments themselves have concluded.
As planned, this repository has therefore been archived.

[`embedded-cal`]: https://github.com/lake-rs/embedded-cal
[issue 1]: https://github.com/lake-rs/embedded-cal/issues/1
